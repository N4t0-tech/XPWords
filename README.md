# XPWords

Plataforma de aprendizaje de inglés gamificada para la comunidad del servidor de Discord.
Los estudiantes ganan XP al completar minijuegos, leer recursos y participar en clases,
con su progreso reflejado en un leaderboard.

## Stack

- **Frontend**: React + Vite + React Router
- **Backend**: Node.js + Express
- **Base de datos**: SQLite

## Estructura

```
xpwords/
├── frontend/        # Aplicación React
├── backend/         # API REST
└── bot/             # Discord bot (próximamente)
```

## Primeros pasos

```bash
# Frontend
cd frontend
npm install
npm run dev

# Backend
cd backend
npm install
npm run dev
```
